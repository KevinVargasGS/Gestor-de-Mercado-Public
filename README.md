# 🛒 Registro de Mercado

Mi primer proyecto en Python: un programa de consola para administrar una lista de mercado.

Lo hice el **primer día que empecé a programar** 🚀

## 📋 Descripción

Es un sistema sencillo con un menú interactivo que permite agregar, ver y eliminar productos de una lista de compras. Empieza con algunos productos ya cargados (Arroz, Pasta, Crema de leche y Plátano).

## ✨ Funcionalidades

- **Agregar un producto:** solo se permite si el usuario es mayor de edad (18 años o más).
- **Ver los productos:** muestra la lista actual del mercado.
- **Eliminar un producto:** quita un producto de la lista si existe.
- **Salir del sistema:** cierra el programa.

## 🧠 Conceptos que practiqué

- Listas (`append`, `remove`)
- Bucle `while`
- Condicionales (`if`, `elif`, `else`)
- Entrada de datos con `input()`
- Conversión de tipos con `int()`
- Operador `in` para buscar en una lista
